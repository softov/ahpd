What is not needed for a node to be listed and run a session waits here.

| What | Why it waits | Where it goes |
| --- | --- | --- |
| A profile that names a node, so machines are made on it | a node is listed as one machine today; making machines there is the node's own computer plugin, reached as a nested host | unplanned |
| A client connecting to a node through the hub without the hub owning the session | the hub owns every relayed session, as for any nested host | unplanned |
