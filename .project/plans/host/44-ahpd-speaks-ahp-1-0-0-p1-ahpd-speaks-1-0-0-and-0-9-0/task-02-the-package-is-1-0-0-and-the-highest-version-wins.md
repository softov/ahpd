## Objective

Every package builds against `@microsoft/agent-host-protocol@1.0.0`; `initialize` answers the highest offered version compatible with 1.0.0 or 0.9.0, `-32005` with `supportedVersions` when there is none, and `-32602` for a malformed entry; a nested host's answer is accepted when it is one of the versions offered to it.

## Steps

1. Change the five ranges and the exclude list, then `pnpm install` (this step needs the registry).
2. In `initialize`, keep the array check, call `negotiateProtocolVersion(offered)` inside `try`, and on a throw answer `RpcError(-32602, ...)` naming the entry; treat a non-string entry as malformed rather than dropping it.
3. `undefined` from it keeps today's `-32005` with `{ supportedVersions: [...SUPPORTED_PROTOCOL_VERSIONS] }`.
4. In `nested.ts`, compare the answer with the list it offered, not with `PROTOCOL_VERSION`.
